# ADR-0003: 단가 계산 시 단계별로 반올림한다

- **상태**: Accepted
- **날짜**: 2026-11-13
- **결정자**: @ljh3534
- **관련**: PR #12 리뷰 [SHOULD] 코멘트

## 배경
PR #12 리뷰에서 "단계마다 `Math.round`를 하면 반올림 오차가 누적된다"는 [SHOULD] 코멘트가 있었다. AdPrice의 핵심 가치는 **근거의 투명성** — 사용자가 화면의 breakdown 표만 보고 최종 금액을 검산할 수 있어야 한다.

## 검토한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| A. 원본 곱으로 최종값 계산, 표시만 반올림 | 수학적으로 정확 | 표의 마지막 행과 최종 금액이 수 원 달라 "계산이 틀렸다"는 오해 |
| B. 단계마다 원 단위 반올림 | 표의 각 행 × 계수 = 다음 행이 항상 성립, 마지막 행 = 최종 금액 | 원본 곱과 최대 수 원 차이 |

## 결정
대안 B — 각 단계 결과를 원 단위로 반올림하고 그 값을 다음 단계 입력으로 쓴다.

## 결과
- 좋아지는 점: breakdown 표가 그대로 검산 가능하다.
- 감수할 점: 최대 4원 내외의 오차. 단가 범위(±15%)에 비해 무시 가능한 수준이다.
- 후속 작업: 없음.

## 재검토 조건
견적서(PDF) 기능에서 원 단위 정확도를 요구하는 사용자가 생기면 재검토한다.
