# ADR-0002: 계산 계수를 JSON 설정 파일로 분리한다

- **상태**: Accepted
- **날짜**: 2026-11-13
- **결정자**: @ljh3534
- **관련**: #6, PR #12, PRD 8장 비기능 요구사항

## 배경
v1 계수는 추정치이며 2학기에 실제 시장 데이터로 보정할 예정이다. PRD는 "계수를 하드코딩 없이 조정 가능"할 것을 요구한다. 또한 개발자가 아닌 사람(마케터)도 계수 변경을 제안할 수 있어야 한다.

## 검토한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| A. TS 상수로 하드코딩 | 타입 안전 | 계수 조정 = 코드 변경, 비개발자 기여 어려움 |
| B. `src/coefficients.json` | 비개발자도 diff를 읽기 쉬움, `resolveJsonModule`로 타입 추론 | 스키마 검증 필요 |
| C. 원격 API/DB | 배포 없이 변경 | 서버 필요 — v1 범위(정적 사이트) 초과 |

## 결정
계수를 `src/coefficients.json`으로 분리하고, `version` 필드로 계수 세트의 버전을 표기한다. 화면 하단에 계수 버전을 노출한다.

## 결과
- 좋아지는 점: 계수 변경 PR의 diff가 숫자 몇 개로 끝나 리뷰가 쉽다. CODEOWNERS로 계수 파일만 별도 리뷰어 지정 가능.
- 감수할 점: JSON에 잘못된 키가 들어가도 컴파일 단계에서 일부만 잡힌다 → 단위 테스트로 보완.
- 후속 작업: 2학기에 JSON Schema 검증을 CI에 추가.

## 재검토 조건
계수를 사용자별로 커스터마이즈해야 하거나 실시간 업데이트가 필요해지면 대안 C를 재검토한다.
